# 图片资源目录

将专题配图放入此目录，HTML 页面会引用这里的本地图片。

## 需要的图片

| 文件名 | 用途 | 建议尺寸 | 推荐主题 |
| --- | --- | --- | --- |
| `cover.jpg` | 首页封面 + 第一期封面 | 800 × 280 | 柔和光线、植物叶片、安静氛围、暖色调 |
| `author.jpg` | 第一期"伊尔斯·桑德"概念图 | 800 × 220 | 书、茶杯、阅读、温暖室内 |
| `traits.jpg` | 第一期"四种真实样貌"概念图 | 800 × 220 | 抽象情绪、连接、平静、深度感 |

## 推荐图库

- [Unsplash](https://unsplash.com)
- [Pexels](https://www.pexels.com)
- [Pixabay](https://pixabay.com)

## 搜索关键词参考

- 封面：`soft light plant`, `minimal plant warm beige`, `calm botanical`, `gentle morning light`
- 作者/阅读：`cozy reading book tea`, `open book warm light`, `quiet study corner`
- 四种样貌：`abstract emotion`, `empathy connection`, `mindfulness calm`, `soft abstract`

## 配色建议

为保持页面风格统一，建议选择偏暖、低饱和度的图片，主色调可参考：

- 背景米色：`#f8f6f2`
- 强调棕色：`#8b7355`
- 浅卡其：`#e8e0d4`

图片放入本目录后，运行 `python scripts/md_to_html.py` 重新生成第一期 HTML 即可生效。
